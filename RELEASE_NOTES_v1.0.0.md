# Synoetis v1.0.0 — Official First Release 🚀

**Synoetis** is an offline-first desktop operating system and second brain crafted specifically for software builders, computer science students, and engineering practitioners. 

Built on **Tauri v2, Rust 2021, React 18, and SQLite**, Synoetis delivers sub-millisecond local speed, zero telemetry, and an integrated cognitive tool suite.

### ✨ Highlights & Key Capabilities

- **🗂️ Spaced Repetition (SRS Engine)**: Algorithmic Leitner/SM-2 review deck covering both DSA algorithm patterns and Knowledge Hub notes with customizable quality scores.
- **💻 Technical DSA & Problem Vault**: Problem tracking across 12 core algorithmic categories with time/space complexity notes and difficulty heatmaps.
- **💼 Career OS**: Fluid pointer-based drag-and-drop Kanban pipeline across 6 workflow stages and an interview debrief question vault.
- **🎓 Academic Timetable & GPA Simulator**: Monday–Friday class schedule matrix and real-time cumulative CGPA projection against target honors.
- **🧠 Knowledge Hub & Block Notes**: Notion-style draggable block documentation with `/` slash commands and bidirectional Markdown folder export/import with YAML frontmatter.
- **⏱️ Deep Work & Focus Timer**: TopBar countdown indicator, Pomodoro (25m/50m/5m) intervals, audio completion chimes, and background system tray docking.
- **🛠️ Developer Snippet Vault**: Instant-access CLI cheat sheets for Git, Docker, Kubernetes, and Linux shell with global `Ctrl+K` omnisearch.
- **🎨 Warm Obsidian & Nude Design System**: Custom frameless window with native controls, seamless dark/light modes, and configurable dashboard widgets.
